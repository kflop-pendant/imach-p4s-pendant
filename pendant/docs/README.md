# iMach P4-S Pendant — Documentation

Reference documentation for the VistaCNC iMach III P4-S -> KFLOP/KMotionCNC
bridge project.

## Contents
- KEYMAP.md         Complete USB report / button bitmap (the authoritative decode).
- INSTALL_GUIDE.md  Step-by-step setup for installing this pendant on your own
                    KFLOP machine.
- manuals/          Where the vendor reference manual lives (see manuals/README.md).

## Note on vendor manuals
The vendor PDF is **not** redistributed in this public repo — it is a third-party
copyrighted document. `manuals/README.md` links to the official VistaCNC download
instead. The same applies to any Dynomotion material: link, don't re-host.
